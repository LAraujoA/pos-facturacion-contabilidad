# Guía de Contribución para Desarrolladores

Para conocer el flujo de trabajo en Git, la rama base obligatoria (`version/1.0`), la arquitectura del proyecto y qué archivos modificar según la tarea, por favor consulta el documento oficial:

👉 **[Guía de Desarrollo y Onboarding (docs/GUIA_DESARROLLO.md)](docs/GUIA_DESARROLLO.md)**

---

### Resumen Rápido:
1. **Rama Base de Trabajo:** `version/1.0`
2. **Crear tu rama de tarea:** `git checkout -b feature/nombre-de-tu-tarea`
3. **Ejecutar el proyecto:** `npm start` (o `npm run dev`)
4. **Abrir Pull Request:** Con destino a `version/1.0`.
